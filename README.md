# 🔎 AI Job Search Agent

![CI](https://github.com/marizariamor/ai-job-search-agent/actions/workflows/ci.yml/badge.svg)

**AI-агент для поиска работы на базе Claude Code: собирает вакансии, отсеивает неподходящие, скорит по профилю и готовит отклики — с подтверждением человеком на каждом шаге.**

Я использую его для собственного поиска работы. Задача: вручную просматривать 14 Telegram-каналов и 4 сайта (hh.ru, Хабр Карьера, getmatch, LinkedIn) — это часы в день, а большая часть вакансий отпадает по одним и тем же причинам: «только из РФ», нужен свободный английский, офис, роль на самом деле разработческая.

## Как устроен

```
 Источники                     Фильтр и скоринг              Человек               Отклик
 ─────────                     ────────────────              ───────               ──────
 Telegram-каналы ─┐                                      ┌─► таблица соответствия ─┐
 (этот репозиторий)│                                     │   требованиям           │
                   ├─► стоп-правила ─► скоринг по ─► шортлист                       ├─► «да» ─► отправка
 hh.ru, getmatch, ─┘   (локация, офис,  профилю          │   сопроводительное ─────┘           + журнал
 Хабр, LinkedIn        техроль, англ.,                   └─► письмо под вакансию
 (браузер)             зарплата)
```

| Шаг | Чем выполняется |
|---|---|
| Сбор из Telegram | `job_agent/telegram.py` — публичные веб-превью `t.me/s/<канал>`, без входа и токенов |
| Сбор с сайтов | Claude Code + браузерная автоматизация в браузере кандидата (вход выполняет кандидат): [`browser/`](browser/) |
| Фильтр и скоринг | `job_agent/scoring.py` + профиль `config/profile.example.json` |
| Шортлист | `job_agent/report.py` → Markdown-таблица со скором и флагами |
| Таблица соответствия и письмо | Claude по правилам [`CLAUDE.md`](CLAUDE.md): 5–7 требований вакансии → реальный опыт → ✅/⚠️/❌ |
| Отправка | только после явного «да» человека |

## Чему научили отказы

Правила фильтра не придуманы заранее — каждое появилось после реального отказа и закреплено тестом:

| Отказ | Причина | Правило в агенте |
|---|---|---|
| Delivery Manager (продуктовая IT-компания) | роль про CI/CD и релизы + шаблонное письмо | отсеивать технические роли; письмо — по пунктам требований вакансии |
| Руководитель проекта AI-платформы | нужен опыт архитектуры AI-платформ + офис | то же + проверять полный текст, а не карточку в выдаче |
| Менеджер IT-проектов | в отклик подставилась зарплата выше вилки | зарплата в отклике — не выше потолка вилки, при скрытой вилке — спросить кандидата |
| Руководитель аналитики | основной инструмент — SQL и Python | отсеивать до прокачки навыка |
| Несколько вакансий «удалённо» | на деле «удалённо из России», кандидат за рубежом | «только РФ» → пропуск, если нет ГПХ/ИП |

## Результаты (сентябрь 2026)
- ~80 вакансий отобрано и проверено вручную, **24 отклика**.
- **Первое приглашение** — в AI-компанию, на роль, связанную с Claude Code.
- Каналы проверены на активность: из 25 кандидатов в источники оставлено 9 — [`config/channels.json`](config/channels.json).

## Принципы
- **Human-in-the-loop:** агент не отправляет отклики, не заполняет анкеты и не указывает зарплату без подтверждения.
- **Без паролей:** вход на сайты всегда выполняет человек.
- **Без персональных данных в репозитории:** профиль — пример, реальный хранится локально (`config/profile.local.json` в `.gitignore`).
- **Тесты на правила:** каждое стоп-правило покрыто тестом с формулировкой из реальной (обезличенной) вакансии.
