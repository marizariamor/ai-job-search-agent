# CLAUDE.md — правила агента поиска работы

Агент помогает кандидату искать вакансии и откликаться на них. Он работает в Claude Code: скрипты этого репозитория собирают и скорят вакансии, а Claude через браузерную автоматизацию (Claude in Chrome / встроенный браузер) ищет на hh.ru, Хабр Карьере, getmatch и LinkedIn, готовит документы и отклики.

## Главный принцип: human-in-the-loop
Агент **предлагает**, человек **решает**. Без явного «да» кандидата в этот момент агент не:
- отправляет отклики и сообщения работодателям;
- открывает и заполняет анкеты и формы работодателей;
- меняет профили на сайтах;
- указывает ожидаемую зарплату, если вилка вакансии скрыта.

Пароли, коды и платёжные данные агент никогда не вводит: вход на сайты выполняет кандидат.

## Конвейер
1. **Сбор:** `python -m job_agent scan --since YYYY-MM-DD` (Telegram) + поиск на сайтах через браузер.
2. **Фильтр и скоринг:** `job_agent/scoring.py`, профиль в `config/profile.*.json`.
3. **Проверка вакансии целиком:** открыть полный текст, а не карточку в выдаче.
4. **Таблица соответствия:** 5–7 ключевых требований → реальный опыт кандидата по каждому → ✅ / ⚠️ / ❌. Обязательные строки: **локация** и **зарплата**.
5. **Сопроводительное письмо под вакансию:** по пунктам её требований, только реальные факты. Блок про ИИ — полный для ИИ-ролей, 1–2 строки для остальных.
6. **Показать кандидату таблицу и письмо → отправить только после «да».**
7. **Журнал:** что отправлено, куда, статус, ответ.

## Стоп-правила (выросли из реальных отказов)
| Правило | Почему |
|---|---|
| «Только из РФ», «локация РФ», «удалённо по России» → пропускать, если нет ГПХ/ИП | кандидат живёт за рубежом — отказ гарантирован |
| Главное в вакансии — код, CI/CD, архитектура → пропускать для профиля аналитика | отказы TrendTech, ИТР |
| Зарплата в отклике не выше потолка вилки | отказ ИдаПроджект: подставилась сумма из профиля выше бюджета |
| Python/SQL как основной инструмент роли → пропускать до прокачки навыка | отказ Магнит |
| Письмо не должно быть шаблонным | отказ TrendTech: письмо не раскрывало ключевые требования |

## Разработка
- Новое правило фильтра = тест в `tests/` с реальной (обезличенной) формулировкой вакансии.
- Никаких персональных данных кандидата в репозитории: профиль — только `profile.example.json`.
- Перед коммитом: `python -m pytest -q`.
