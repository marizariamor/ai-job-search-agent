# Поиск на сайтах через браузерную автоматизацию

Сайты hh.ru, getmatch и LinkedIn рендерятся в браузере и требуют входа в аккаунт. Поэтому этот шаг агент выполняет **в браузере кандидата** (Claude in Chrome / встроенный браузер Claude): кандидат входит в аккаунт сам, агент выполняет поиск на странице.

## hh.ru — поиск по названию вакансии
Файл [`hh_search.js`](hh_search.js): запускается на открытой странице hh.ru, делает несколько поисковых запросов по языку запросов hh (`NAME:(...)`) и возвращает компактный список: id, название, компания, зарплата.

Пример запроса:
```
NAME:("AI" OR "ИИ" OR "LLM") AND NAME:(проект* OR project OR внедрен* OR аналитик)
schedule=remote · search_period=7 · salary=100000
```

## getmatch — публичный API выдачи
Выдача getmatch берётся из `/api/offers` (тот же источник, что у страницы). Фильтр по специализации — slug:
```
/api/offers?sa=100000&l=remote&sp=project_management&limit=50
```
Slug'и специализаций: `/api/specializations` (project_management, product_management, business_analyst, data_analyst_bi …).

⚠️ «📍 Россия · Удалённо» на getmatch = удалённо **из России**. Для кандидата за рубежом такие вакансии отсеиваются (см. стоп-правила в `CLAUDE.md`).

## Отклик
Агент заполняет сопроводительное письмо и нажимает «Откликнуться» **только после подтверждения кандидата** — см. `CLAUDE.md`.
